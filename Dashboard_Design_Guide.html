Before you build · Concept 1
How Power BI visuals work
Before placing a single chart, understand the three-part system behind every Power BI visual. Once this clicks, building any chart becomes predictable.
1
Every visual has three parts: Fields, Filters, Format
▼
PanelWhat it controlsWhere to find it
FieldsWhat data goes into the visual — axis, values, legend, tooltipsRight panel — appears when a visual is selected
FiltersWhich rows are included — limit to top 10, specific status, date rangeRight panel — Filters tab
FormatHow it looks — colours, fonts, titles, borders, data labelsRight panel — paintbrush icon
💡 Building a visual is always the same process: (1) pick the visual type, (2) drag fields into the right slots, (3) add filters if needed, (4) format to make it readable. In that order, every time.
2
How to add a visual to the canvas
▼
  1. Click on a blank area of the canvas to make sure nothing is selected.
  2. In the Visualizations pane (right side), click the icon of the chart type you want. A blank placeholder appears on the canvas.
  3. Drag fields from the Fields pane (far right) into the field wells in the Visualizations pane — or drag directly onto the canvas placeholder.
  4. Resize by dragging the corners. Move by dragging the title bar of the visual.
💡 If you click somewhere on the canvas first and then click a visual type, the new visual might replace your selection. Always click blank canvas space first before adding a new visual.
3
Cross-filtering — Power BI's superpower
▼

By default, clicking a bar or data point in any visual automatically filters every other visual on the same page. This is called cross-filtering and it's what makes Power BI dashboards interactive without any extra setup.

For example: clicking the "Remote" bar in your work setup chart will automatically update the postings-over-time line chart, the top companies chart, and KPI cards — all showing only Remote job data. No configuration needed.

⚠️ This works because of the relationships you set up in Phase 2. If a visual isn't filtering correctly when you click another one, it usually means there's a missing or incorrect relationship in the model.

Choosing the right chart type
The chart type should match the question being answered. Using the wrong chart makes data harder to read — not more impressive. Here's the decision framework.
1

▼

Compare categories (ranked)Column chart (vertical)Top companies by postings

⚠️ Avoid pie charts with more than 4 categories — they become impossible to read. Use a bar chart instead. And never use 3D charts — they distort the data visually and make comparisons harder, not easier.
Before you build · Concept 3
Design principles for beginners
A dashboard that looks professional isn't about being fancy — it's about being consistent, clean, and purposeful. These five rules will make your portfolio stand out.
1
The 5 design rules to follow
▼
RuleWhat it means in practice
One colour palettePick 1–2 main colours and use them consistently. Don't let Power BI auto-colour every chart differently.
Every visual needs a title"Jobs by Work Setup" not "Chart 1". Titles tell the reader what to look for before they even read the data.
Less is moreIf a visual doesn't add new information, remove it. A clean page with 5 good visuals beats a cluttered page with 12.
Align everythingUse Power BI's Format → Align tools to make sure visuals line up on a grid. Misaligned visuals look amateur.
Data labels only when neededDon't add data labels to every chart — they clutter line charts. Add them only when the exact number matters (KPI cards, funnel stages).
💡 Colour suggestion for your dashboard

Use a dark navy or dark grey background (#1e1e1c or #0d1b2a) with one accent colour (teal #2eb8c8 or gold #f0a500) for highlighted bars and KPI values. White text on dark background. This colour scheme reads as professional and analytical — suitable for a data portfolio.

Or use Power BI's built-in Executive or Frontier theme (View tab → Themes) as a clean starting point.

Before you build · Setup
Set up your 4 report pages
Before adding any visuals, create all four pages and name them properly. This gives you a clear structure to work within.
1
Create and name the pages
▼
▶ Bottom of the canvas → + button → right-click tab to rename
  1. At the bottom of the Power BI canvas, click the + button to add a new page. Repeat until you have 4 pages.
  2. Right-click each page tab → Rename page. Name them exactly: Market Overview, Skills Analysis, Salary Insights, Recruitment Funnel.
  3. Right-click the first blank page that Power BI created by default → Delete page if it's empty and unnamed.
💡 Page names appear at the bottom of your dashboard when published. Clean, descriptive names tell viewers exactly where to go — which matters for a portfolio presentation.
2
Set canvas size for all pages
▼
  1. Click on a blank area of the canvas (nothing selected).
  2. In the Format pane (paintbrush), find Canvas settings.
  3. Set Type to 16:9 — this is the standard widescreen ratio and looks best when presenting or screenshotting for a portfolio.
  4. Repeat for all 4 pages.

Page 1 — Market Overview
KPI cards
KPI cards show a single number prominently. They're the first thing viewers read on any page — keep them bold, large, and labelled clearly.
1
Build the Total Job Postings card
▼
▶ Visualizations pane → Card icon (looks like a rectangle with a number)
  1. Click a blank area of the canvas, then click the Card visual in the Visualizations pane.
  2. In the Fields well, drag [Total Job Postings] from _Measures into the Fields slot.
  3. The card shows the number. Click the Format tab (paintbrush icon).
  4. Under Callout value → increase font size to 36–48pt, set colour to your accent colour.
  5. Under Category label → change the text to Job Postings, set font size to 12pt.
  6. Turn off the card border or set a subtle one — your choice.
💡 Repeat the same process for Total Applications, and for unique companies use dim_jobs[company] in a Card visual set to Count Distinct (click the dropdown arrow next to the field in the well → Count Distinct).
Page 1 — Market Overview
Postings over time — line chart
This shows how many jobs were posted each month from January to June 2026. It's the only trend visual on the page and gives context to all the other numbers.
1
Build the line chart
▼
▶ Visualizations pane → Line chart icon
  1. Click the Line chart icon in the Visualizations pane.
  2. X-axis: drag dim_date[YearMonth] — this gives "2026-01", "2026-02" etc. in chronological order.
  3. Y-axis: drag [Total Job Postings] from _Measures.
  4. In Format → Lines → increase stroke width to 3px for visibility.
  5. Turn on Markers so each month has a dot on the line.
  6. Set the title to Job Postings by Month.
⚠️ If the X-axis sorts alphabetically instead of chronologically (April before January), click the YearMonth column in the Fields panel → Column tools tab → Sort by Column → choose a numeric month column. This is why we created YearMonth as "2026-01" format — it sorts correctly as text.
Page 1 — Market Overview
Jobs by role & work setup
Two visuals that answer "which roles are most common?" and "how are jobs split between Remote, Hybrid, and Onsite?"
1
Top 10 job titles — horizontal bar chart
▼
▶ Visualizations pane → Clustered bar chart (horizontal bars)
  1. Click Clustered bar chart (the horizontal one — bars go left to right).
  2. Y-axis: dim_jobs[job_title]
  3. X-axis: [Total Job Postings]
  4. In the Filters pane → job_title → set filter type to Top N → Top 10 by Total Job Postings → Apply filter.
  5. Sort the bars: click the ... menu on the visual → Sort by → Total Job Postings → Descending.
  6. Title: Top 10 Job Titles
💡 Horizontal bar charts are better than vertical column charts for long category names like job titles — the labels have room to display fully without rotating.
2
Work setup breakdown — donut chart
▼
▶ Visualizations pane → Donut chart icon
  1. Click Donut chart in the Visualizations pane.
  2. Legend: dim_jobs[work_setup]
  3. Values: [Total Job Postings]
  4. In Format → Detail labels → set label to show both the category name and percentage.
  5. Title: Work Setup Distribution
💡 Donut charts work well here because there are only 3 categories (Remote, Hybrid, Onsite). Three slices are easy to read. If you had 8+ categories, switch to a bar chart instead.

Page 2 — Skills Analysis
Top skills bar chart
The main visual on this page — a ranked horizontal bar chart showing which skills appear in the most job postings. This works through the bridge_job_skills table you built in Phase 2.
1
Build the top 15 skills chart
▼
▶ Clustered bar chart → dim_skills + [Jobs Requiring Skill]
  1. Add a Clustered bar chart (horizontal).
  2. Y-axis: dim_skills[skill_name]
  3. X-axis: [Jobs Requiring Skill] from _Measures
  4. In the Filters pane → skill_name → Top N → Top 15 by Jobs Requiring Skill → Apply.
  5. Sort descending by Jobs Requiring Skill.

Page 2 — Skills Analysis
Skills by job title — Matrix visual
A matrix visual (like a pivot table) shows which skills are required by which job titles. It lets you spot patterns — for example, SQL appears across almost every role while PyTorch is specific to AI/ML roles.
1
Build the matrix visual
▼
▶ Visualizations pane → Matrix icon (looks like a grid)
  1. Click the Matrix icon in the Visualizations pane.
  2. Rows: dim_jobs[job_title]
  3. Columns: dim_skills[skill_name]
  4. Values: [Jobs Requiring Skill]
  5. In Format → turn off Row subtotals and Column subtotals — they clutter the matrix.
  6. In Format → Cell elements → turn on Data bars — this adds a coloured bar inside each cell proportional to the value, making patterns much easier to read visually.
  7. Title: Skills by Job Title
💡 The matrix might be wide if there are many skills. Resize it to take up most of the page width, and use the scroll bar to explore. Alternatively add a slicer for skill_name and let the viewer filter to their skills of interest.

Page 4 — Recruitment Funnel
Recruitment funnel visual
The funnel chart is the centrepiece of this page. It visually shows the drop-off from 2,659 total applications down to 163 hired — making the conversion story immediately obvious.
1
Build the funnel chart
▼
▶ Visualizations pane → Funnel chart icon
  1. Click the Funnel chart icon in the Visualizations pane.
  2. The funnel needs a Category field and a Values field. The easiest approach is to use a table that lists all your stage counts.
  3. Add a Table visual first and put all 6 stage measures as columns — this lets you verify the numbers before building the funnel.
  4. For the funnel itself: create a What-if parameter or use the Field parameter feature — or the simplest approach: add all 6 stage measures directly as Values in the funnel's Values well, one by one.
⚠️ Power BI's funnel chart is designed for a Category + single Value field. The cleanest way to show all 6 stages is to add a small summary table visual instead of a funnel if the funnel layout is tricky — a table with Stage and Count columns clearly shows the drop-off with data bars enabled.
💡 Alternatively: use a Clustered column chart with all 6 stage measures as separate series — this creates a visual waterfall effect that shows the funnel clearly without the native funnel chart limitations.

Slicers & cross-filtering
Slicers are the dropdown or button filters that let viewers interact with your dashboard. Adding 1–2 slicers per page makes the dashboard feel genuinely interactive rather than static.
1
Add slicers to each page
▼
▶ Visualizations pane → Slicer icon
PageSuggested slicer fieldStyle

💡 To change slicer style: click the slicer → Format pane → Slicer settings → Style → choose Dropdown, List, or Buttons. Buttons look most modern for small sets of options (work_setup has 3 values — perfect for buttons).
2
Control which visuals a slicer affects
▼
  1. Click the slicer to select it.
  2. Go to Format tab in the ribbon → Edit interactions.
  3. Small icons appear on every other visual — a filter icon means the slicer affects it, an X means it doesn't. Click to toggle.
  4. Turn off the slicer's effect on KPI cards if you want them to always show the overall total regardless of filters.
Polish & Publish
Formatting & theme
Consistent formatting is what separates a student project from a portfolio piece. These are the finishing touches that take 20% of the time but make 80% of the visual difference.
1
Apply a theme
▼
▶ View tab → Themes
  1. Go to View tab → click Themes.
  2. Browse the built-in themes. Executive or Frontier are clean and professional — good for a data portfolio.
  3. Click a theme to apply it to all pages at once.
  4. You can customise further: Themes dropdown → Customize current theme → change the primary colour to match your chosen accent colour.
💡 Apply the theme first before formatting individual visuals — otherwise your manual formatting gets overwritten when you apply a theme.
2
Formatting checklist — apply to every visual
▼
SettingRecommended value
Visual titleEvery visual has a clear, descriptive title. Font size 12–14pt.
Axis titlesTurn OFF axis titles — the visual title already explains the axes.
Grid linesLight grey, 1px — or turn off entirely for a cleaner look.
BackgroundTransparent or very light grey — let the page background show through.
BorderSubtle shadow or thin border — makes visuals feel like cards.
Data labelsOn for KPI cards and funnel. Off for line charts and dense bar charts.
LegendOnly show if there are multiple series. Position: Top for most visuals.
